# CA1: Requirements and Domain Analysis

**Author:** Elisha Seruma

This repository contains the Object-Oriented Analysis and Design CA1 work for Kerry Enterprise Development Network (KEDN).

KEDN provides short courses, workshops and one-to-one mentoring for new and growing businesses. Participants can request event support, mentoring or both. Staff must assess requests, arrange suitable support, track progress and retain earlier decisions.

The scenario describes information spread across spreadsheets, forms, email and notes. This analysis considers a service coordination system that makes request status, responsibilities, allocations and outcomes clearer. It covers requirements and domain understanding rather than software implementation.
